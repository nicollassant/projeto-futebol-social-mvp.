# Futebol Social — MVP

Aplicação web responsiva para apoiar a gestão e a divulgação de um projeto social que oferece aulas gratuitas de futebol para crianças e adolescentes.

## Objetivo

Facilitar a organização dos cadastros de alunos, apresentar informações públicas sobre o projeto e permitir que pessoas ou empresas manifestem interesse em apoiar a iniciativa.

## Escopo inicial

- Página pública com apresentação, atividades e orientações de participação.
- Área administrativa para gerenciamento de alunos e responsáveis.
- Formulário para manifestação de interesse de apoiadores.
- Interface responsiva, utilizável em computadores e celulares.

## Tecnologias planejadas

- Python e Flask no backend.
- HTML5, CSS3 e JavaScript no frontend.
- MySQL para persistência de dados.
- SQLAlchemy para acesso ao banco de dados.
- Flask-Login para gerenciamento de sessões administrativas.
- Pytest para testes automatizados.

## Situação do desenvolvimento

Este repositório está em construção. A primeira etapa implementa a estrutura básica da aplicação e sua página inicial. As funcionalidades de autenticação, banco de dados e cadastros serão desenvolvidas e testadas em etapas posteriores.

## Como executar

As instruções de instalação e execução serão atualizadas conforme a estrutura da aplicação for implementada.

## Privacidade

Não utilize dados reais de crianças, adolescentes, responsáveis ou participantes nos exemplos, testes ou commits deste repositório.
